# 🌟 Welcome to My GitHub Profile 🌟

## About Me

I focus on **3D Vision** and **3D Point Cloud** technologies. My work primarily involves advancing the state-of-the-art in 3D data processing, computer vision, and machine learning.

## 🧑‍💻 Research Interests

- **3D Point Cloud learning** semantic segmentation， especially applying sequence models (e.g., Attention, SSMs) to serialized point clouds.
- Other interests: **Spatial Intelligence**，**3D reconstruction** (e.g., MVSs, 3DGS, VGGT)、**Self Supervised Learning** (e.g., Superpoint, Sonata)
